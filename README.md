# 🎤 Speech to Text & Text to Speech Flutter App

A simple Flutter application that provides both **Speech-to-Text (STT)** and **Text-to-Speech (TTS)** functionality. The app allows users to convert spoken words into text and convert written text into natural speech using Flutter packages.

## ✨ Features

- 🎙️ Real-time Speech-to-Text conversion
- 📝 Display recognized speech instantly
- 🔊 Convert typed text into speech
- 📱 Clean and responsive Flutter UI
- ⚡ Fast and lightweight implementation
- 🌐 English (en-US) language support

## 🛠️ Built With

- **Flutter**
- **Dart**
- `speech_to_text` package
- `flutter_tts` package

## 📂 Project Structure

```
lib/
├── main.dart
└── page/
    ├── speech_screen.dart
    └── text_screen.dart
```

## 🚀 Getting Started

1. Clone the repository.
2. Run:
   ```bash
   flutter pub get
   ```
3. Connect a device or start an emulator.
4. Run:
   ```bash
   flutter run
   ```

## 📦 Dependencies

```yaml
speech_to_text
flutter_tts
```

## 📱 How It Works

### Speech to Text
- Tap the microphone button.
- Speak into the device.
- Your speech is converted into text and displayed on the screen.

### Text to Speech
- Enter any text.
- Press the Speak button.
- The application reads the text aloud using Text-to-Speech technology.

## 🎯 Purpose

This project was developed as a Software Engineering/Flutter project to demonstrate the integration of speech recognition and text-to-speech technologies in a mobile application.
